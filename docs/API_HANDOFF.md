export type RunStatus =
  | "queued" | "planning" | "searching" | "reading"
  | "verifying" | "synthesizing" | "completed"

  summary: string;

  id: string;

## Semantics and integrity
queued -> planning -> searching -> reading -> verifying -> synthesizing -> completed. completed, partial, failed, cancelled are terminal. Partial may retain a report; failed/cancelled must never imply success. Null is unknown/not reported. Timestamps are ISO-8601 UTC. Source support is not independent fact-checking. Excerpts are supplied data, never generated by the frontend. Claims reference evidence IDs, evidence references both claim and source IDs, comparison references claim IDs. Broken or duplicate references are diagnosed by identifier only and safely excluded by the evidence resolver; no excerpt is invented. Runtime shape validation rejects malformed JSON but retains structurally valid partial data for honest unavailable states.

## HTTP and polling
POST sends Content-Type: application/json, never automatically retries. GET status uses cache: no-store. HTTP errors use ApiError envelope above; the client deliberately presents fixed safe messages rather than arbitrary server text. Handle 400 validation, 404 absent/expired, 429 throttled, 500/502/503 unavailable, network, invalid JSON/schema and timeout. Future poller: 2 seconds while visible/active, no overlapping requests, stop on terminal/route change/unmount, abort pending work and timers. GET-only bounded exponential backoff (2/4/8 seconds, maximum 3 transient retries), honor Retry-After once agreed. Phase 2 adapter accepts AbortSignal and has a 10-second request timeout; polling UI belongs to Phase 4.

## Configuration
NEXT_PUBLIC_DATA_MODE=mock or real; default mock. NEXT_PUBLIC_API_BASE_URL=http://localhost:8000. Real mode requires a valid HTTP(S) URL without credentials/query/hash and never falls back to mock. Public values contain URLs/mode only; all inference/search secrets belong on backend. Dev 1 owns CORS for local/deployed origins. Mock runs live only in the adapter instance and reset on reload; deterministic clock and terminal outcome are injectable for tests. All mock material is fictional DEMO ONLY, with example.org URLs.
